# 26 级第三期考核任务：TB6612 电机驱动与水平转盘偏航角闭环控制

基于 **STM32F103C8T6 + CubeMX/HAL** 的水平转盘闭环工程：TB6612FNG 硬件 PWM 驱动（正转 / 反转 / 刹车 / 死区补偿）、TIM4 定时器节拍建立 200Hz 控制周期、MPU6050 陀螺 Z 轴积分得到 Yaw、位置式/增量式 PID 带输出限幅与积分抗饱和、串口命令 `SET/START/STOP` + PID 在线整定、VOFA+ 双通道波形、软件限位、±180° 最短路径。

电机自带的**正交编码器**也接了进来，除了堵转保护与转速观测，还可以作为独立的闭环反馈源（`FB=ENC`）。整定顺序是先编码器环、再陀螺环；**验收用陀螺反馈**，因为编码器装在电机侧，看不出传动回程间隙（见 4.11）。

- 版本：**v1.2.8**
- 主控：STM32F103C8T6，HSE 8MHz × PLL9 = **72MHz**
- 工具链：Keil MDK 5.43a（ARMCC V5.06 + MicroLIB，-O2）
- 构建状态：**0 Error / 0 Warning**；Code 30628 B / RO 896 B / RW 260 B / ZI 1836 B；产物 `MDK-ARM/Objects/Task3_YawPID.hex`（89450 B）
- 主机端单元测试：**55 项断言全部通过**（`tools/host_test/build_and_run_task3.ps1`）
- 反馈源与默认增益：`FB=ENC` → `30 / 1.5 / 2`、ZUPT 开；`FB=IMU` / `FB=FUSE` → `12 / 0.8 / 0`、ZUPT 关。**切 `FB=` 时自动套用**，见 4.1

### TB6612 电源（比引脚更容易接错）

```
 VM  <- 电机电源 6~12V（独立电池/电源，绝不可从开发板 5V 取）
 VCC -> 3V3   ★必须 3.3V：VIH = 0.7×VCC，VCC=5V 时门限 3.5V，3.3V 逻辑推不动
 GND -> 与开发板、电机电源负极共地
 VM-GND 就近并 100µF 电解 + 100nF 瓷片，抑制换向火花干扰 I2C
 AO1/AO2 -> 电机两根线
```

- **电机两根线本机是接反的**：`MOTOR_DIR_INVERT` 必须为 **1**，否则"正输出"会让编码器角减小，闭环直接变成正反馈往一个方向加速。默认值已经置 1，接线换了记得改回去。
- **不要开 TIM3 部分重映射**：它会抢走 PB4/PB5/PB0/PB1，和本工程的 STBY(PB0)、编码器/JTAG 脚冲突。
- PA15/PB3 原本是 JTAG 脚，工程里 `__HAL_AFIO_REMAP_SWJ_NOJTAG()` 只保留 SWD，因此可以安全用作编码器输入；两脚都是 **5V 容忍**，编码器用 5V 供电直连也不会打坏 MCU。
- **MPU6050（实为 MPU6500 兼容模块）面朝下**贴在转盘上，Z 轴朝下：实测 `az = −1.02 g`，与竖直方向夹角 2.7~4.8°。朝向由 `GSIG` 补偿：面朝下用 `GSIG=-1`（默认），面朝上用 `+1`。
- AD0 接地为 0x68（代码会自动尝试 0x69）。I2C 接触不良时**不必重启整块板**：插好后发 `IMUINIT` 即可重新探测并自动重做零偏标定。
- 编码器装在**电机轴（减速箱之前）**，折算到转盘的刻度是 `CPD`。本机真值 **6.933 counts/转盘度**（13 线 ×4 倍频 ×48:1 = 2496 counts/rev），早期用的 13.6 恰好是它的 2 倍，所有"度"都差一倍。
- **排线限制约 ±150°**：`LIMIT` 建议 ≤130，留出余量。

## 四、控制原理要点

### 4.1 反馈源（`FB=`）：为什么先调编码器再上陀螺

闭环用的角度有三个来源，可以在线切换（运行中不允许切）：

| 源 | 角度 | 特性 |
|---|---|---|
| `FB=ENC` | 编码器累计角，`edeg += Δcount×SIG/CPD` | 不漂、分辨率 0.07°，但在电机侧，含减速箱齿隙（见 4.11） |
| `FB=IMU` | 陀螺 Z 轴积分 | 直接反映转盘真实角度，无机械耦合，但零偏会漂 |
| `FB=FUSE` | 互补滤波：陀螺负责高频，编码器用 2s 时间常数把低频拉回来 | 兼顾平滑与不漂，但对齿隙误差只能慢修正 |

**切换 `FB=` 会自动套用对应的整定值和 ZUPT 状态**（v1.2.5 / v1.2.7）：

| `FB=` | `Kp/Ki/Kd` | ZUPT | 依据 |
|---|---|---|---|
| `ENC` | 30 / 1.5 / 2 | 开 | 反馈几乎无滞后，可用高带宽 |
| `IMU` / `FUSE` | 12 / 0.8 / 0 | 关 | 闭环套的是转盘，中间有弹性传动和 5° 回程间隙；ZUPT 会冻结慢速积分 |

切换时串口会打印一行确认：`FB=IMU gains -> 1200/80/0 (x100) zupt=OFF`。

**为什么陀螺环必须降带宽**：同一个 `Kp=30`，编码器环稳如磐石（抖动 0.65°），陀螺环却出现 5Hz 极限环（超调 10°、抖动 5.8°、500/599 帧角速度超 200dps）。原因是陀螺看到的是**粘滑冲击**（每次滑动 400dps 的尖峰），而 `Kd` 和"制动增强"都直接挂在角速度上，于是每拍打到限幅、把环路变成 bang-bang。降到 `12/0.8/0` 后同一条"大位移后立刻反向"序列反而全面更好：超调 1.59°、上升 0.171s、稳定 0.222s、静差 −0.03°。

### 4.2 Yaw 积分用 DWT 计时，不用 `HAL_GetTick()`

1ms tick 在 5ms 周期上是 20% 的量化误差，直接把角速度积分成角度会带来系统性刻度误差。`DWT->CYCCNT` 是 72MHz 计数，dt 精度足够；无符号相减自动处理 59.6s 的回绕。

### 4.3 两个角度量

- `cont` 连续累计角：用于**限位**与 PID 输入输出；
- `yaw = wrap180(cont)` 显示角：VOFA+ 画的就是它。

从 +170° 到 -170° 时 `cont` 会走到 190°，这正是"最短路径允许跨 ±180°"与"限位必须按连续角算"能同时成立的原因。

### 4.4 最短路径

`err = wrap180(target - yaw)`，PID 的等效目标取 `cont + err`，于是 ±180 处既不跳变，也天然走短边。

两种验证方式：

- **算法层（任意角度可做）**：转盘在 +20.169° 时发 `SET=-179`，`STAT` 回 `err=+160.831`（= wrap(−179 − 20.169)）；朴素实现会给 −199.17。发 `SET=+179` 时 `err=+158.856`。
- **实机层**：`LIMIT=300` 时 `SET=150` → `START` → `SET=-150`，`cont` 走 `149 → 171 → 210`，即只转 61°，终点 −149.63°。

### 4.5 陀螺零偏标定、温漂与 ZUPT

开机 1.5s 非阻塞标定，标准差给"静止质量"打分（本机 `quality=98`）。

**这颗模块的零偏强烈依赖温度**：上电前几分钟 gz 零偏从 0.04 漂到 0.21 dps（约 0.1 dps/℃），标定过的 0.170 与稳态真值 0.183 只差 0.013 dps。所以规程是：

1. 上电后**预热 2~3 分钟**（温度稳定在 27.9℃ 左右）；
2. 再 `CAL`；
3. 标定后静止漂移可压到 **0.0135 dps ≈ 0.8°/min**。

**ZUPT 的代价要说清楚**：它判"静止"期间把积分 dt 置 0，而慢速转动时编码器很多拍是 0 增量、角速度又低于 1dps 门限，会被整段误判成静止——实测一次手转 97.5°，陀螺只积到 **72%**。因此 `FB=IMU/FUSE` 默认关 ZUPT（见 4.1）；关了并不影响锁定精度：60 秒锁定实测静差 **−0.059°**。

另外零偏在线学习有双闸（编码器静止 500ms + 每次只允许 ±4dps），防止把真实转动学成零偏（早期版本踩过：`BIAS` 被学到 12.7 dps，yaw 以 −12 dps 稳定跑飞）。

### 4.6 死区补偿与实测特性

TB6612 输出不是"给了占空比就转"。真机实测（`DZ=0` 直接给占空比）：

| 占空比 | 0.4 秒转过 | 折算 |
|---|---|---|
| 60‰ | 0.00° | 不动 |
| 90‰ | 0.44° | 几乎不动 |
| 120‰ | 0.15° | 不动 |
| **150‰** | **12.2°** | 起动门限 |
| 180‰ | 16.8° | ≈40 dps |
| 300‰ | 38.8° | ≈100 dps |

死区默认 **145‰**。装上 MPU6050 后线会拖住转盘，静摩擦变大：闭环实测**静摩擦门槛在 188‰~248‰ 之间**，也就是 `DZ=145 + 力度≈60‰` 才勉强起步——这解释了两个现象：

- 小误差（<3°）时 `out < 60`，占空比不到门槛，转盘推不动，只能靠积分慢慢攒（60 秒内能收敛到 0.06°）；
- 一旦越过门槛就是"粘滑"式猛动（79~250 dps），所以死区带来的分辨率下限是**物理上的**，不是增益能解决的。

**这个值强依赖机构状态**，换机构必须重测。

### 4.7 小输出刹车（`BRAKE_OUT_PM`）

闭环输出小到推不动电机时（|out| < 6‰），固件不是滑行而是切 TB6612 的短路刹车。转盘本身有摩擦能停住，但带着速度冲过目标时先刹车能明显压超调。实测同样脉冲后：350‰/0.1s 时滑行多走 8.46°、刹车只走 3.53°（**少 58%**）；500‰/0.08s 时 13.16° vs 5.73°（**少 56%**）。

### 4.8 制动增强：非对称出力

"加速能力"和"制动能力"的需求相反：加速给太大 → 一冲就过（`OMAX=600` 时实测 ±25° 振荡）；制动给太小 → 手一推就顶不住。

所以出力上限做成**非对称**：正常出力受 `OMAX` 限制，**被外力推离目标时**放大 `BRAKE_BOOST_NUM=3` 倍（最多 `OUTPUT_BRAKE_PM=1000‰`）。判据是 **`误差 × 速度 < 0`（正在远离目标）**，并带速度门限：

| 版本 | 判据 | 结果 |
|---|---|---|
| v1.1.3 | "输出与速度方向相反" | 正常减速接近目标时也被放大 → 刹过头，**反向超调 14°** |
| v1.1.4 | `err·v < 0` 且 `\|v\| > 20dps` | 反向超调 0、回位 0.33 s；但慢推（0~15 dps）触发不到 |
| **v1.2.4** | 门限按反馈源区分：编码器 **20dps**、陀螺 **60dps**，且判据改用 `ctl_rate`（见 4.9） | 陀螺环极限环消失；松手回位仍能喷到 240~284 dps |

### 4.9 微分用外部测速 + 陀螺测速再低通

位置差分在 5ms 周期上量化太粗：编码器 1 个计数就是 14.7 dps 的台阶，`Kd` 一放大微分项就被量化噪声打死。`pid_set_rate_source()` + `pid_set_rate()` 允许把干净测速直接喂给微分项。

**陀螺反馈还要再滤一次**（v1.2.4）：陀螺原始角速度带着粘滑冲击（峰值 ±400dps），直接喂给 `Kd` 和制动增强会让 2×400=800pm 每拍打满限幅。做法是 `ctl_rate_update()` 用 `CTL_RATE_TAU_IMU_MS=80ms` 再低通一次，**只给控制用**；`STAT` 与波形里的 `rate` 仍是原始值，方便观察真实角速度。编码器模式不重复加滞后。

### 4.10 软件限位

默认 **±165°**（连续角），本机排线限制约 ±150°，建议 `LIMIT<=130`。接近限位 10° 内只允许往回收方向出力；越限立即刹车并进入 FAULT，必须手动转回后 `CLEAR`。

限位守卫必须按**电机实际转向**判断（`ctl_enc_dir()`：`INV` / `SIG` / 命令符号三者共同决定），否则会出现"往外推被放行、往回拉被全拒"——实测把转盘卡在 +169° 出不来（v1.2.3 修）。

`DUTY/FWD/REV` 同样受限位守卫：剩余角度不足且方向朝外直接回 `ERR:LIMIT`；**点动超过 1.5 s 自动断电**（`MANUAL_TIMEOUT_MS`）。

### 4.11 回程间隙约 5°：编码器看不见的那部分

传动有**约 5° 的回程间隙**。编码器在电机侧，换向时要先空走完这段间隙转盘才动，而这段位移被编码器算进了角度里。实测（同一台机器，`FB=IMU` 记录真实转角）：

| 动作 | 编码器 Δ | 陀螺 Δ（转盘真实转角） | 差值 |
|---|---|---|---|
| 换向后立刻 +30° | 35.19° | 29.62° | **+5.58°** |
| 同方向再 +30° | 30.00° | 29.34° | +0.66° |

后果很直接：**`FB=ENC` 每次换向后，转盘实际会少转 3.6°**，而编码器显示"精确到位、抖动 0.000°"。这是本工程坚持用陀螺做验收反馈的直接原因，也是"编码器环看起来完美但转盘角度不对"的根源。

### 4.12 弹性传动引起的 5Hz 极限环

制动瞬间皮带/齿隙会把能量弹回来（实测 30ms 内反向 149 dps，比电机满速还快），高带宽 PID 会把它激成自持振荡：转盘在 22°~35° 之间以约 5Hz 来回撞，瞬时角速度 ±400dps。

这个现象在 `FB=IMU` 且 `Kp=30/Kd=2` 时稳定复现（306/599 帧角速度超 200dps）。修法是 4.9 的测速低通 + 4.8 的门限区分，之后同类序列只剩 9/599 帧。

排查这类问题的经验：**看波形里"角度"和"角速度"是否自洽**。若角速度积分与角度变化对不上（本工程实测比值 0.891），说明有滤波或门控在中间动了手脚，先把数据链理顺再调参。

## 五、串口命令

115200 8N1，命令与 VOFA+ 数据流共用同一串口；数据帧是 `yaw:...` 小写标签，命令是大写关键字，互不干扰。非法输入统一回 `ERR:<原因>`（`UNKNOWN_CMD` / `SYNTAX` / `RANGE` / `STATE` / `LIMIT` / `LINE_TOO_LONG`）。

| 命令 | 说明 |
|---|---|
| `SET=<角度>` | 设定目标角，如 `SET=-45.5`（也接受 `SET -45.5`）；超限回 `ERR:LIMIT` |
| `START` / `STOP` | 进入 / 退出闭环（STOP 后电机滑行断电） |
| `CAL` | 重新标定陀螺零偏（需静止，约 1.5s；**上电预热后再做**） |
| `ZERO` | 当前角度置 0，目标角同步平移（编码器角、融合角一并清零） |
| `KP=` `KI=` `KD=` | 单独整定一项，立即生效并回显 |
| `PID=<kp>,<ki>,<kd>` / `PID` | 三项一起设 / 打印当前值 |
| `MODE=POS\|INC` | 位置式（默认）/ 增量式 |
| `FB=IMU\|ENC\|FUSE` | 反馈源（仅非 RUN 可切）；**自动套用对应增益与 ZUPT** |
| `CPD=<n>` | 编码器每转盘度多少计数（本机 6.933） |
| `SIG=1\|-1` | 编码器计数方向 |
| `GSIG=1\|-1` | 陀螺安装方向（面朝下 −1，面朝上 +1） |
| `LIMIT=<度>` | 软件限位（30~300） |
| `DZ=<‰>` | 电机死区补偿量 |
| `OMAX=<‰>` | 闭环输出上限（同时写进 PID 的限幅，抗饱和才有效） |
| `KICK=<‰>,<ms>` | 换向"踢一脚"（默认关闭） |
| `INV=ON\|OFF` | 电机方向取反 |
| `ZUPT=ON\|OFF` | 静止冻结积分（`FB=IMU` 时建议关） |
| `BIASAUTO=ON\|OFF` | 怠速零偏在线跟踪 |
| `STALL=ON\|OFF` | 堵转检测（超时 2s；手推测试前请关） |
| `DUTY=<‰>` | 开环点动（仅 IDLE）；1.5 s 自动断电 |
| `IMU` / `IMU=ON\|OFF` | 打一条 / 连续 20Hz 输出六轴原始值（`ax ay az gx gy gzraw gzs temp`） |
| `IMUINIT` | 重新探测 MPU6050（掉线后免重启），成功会自动重做零偏标定 |
| `STREAM=ON\|OFF` / `RAW=ON\|OFF` | 数据流开关 / 追加第三通道角速度 |
| `PROTO=FIRE\|JUST` | FireWater / JustFloat |
| `STAT=ON\|OFF` / `STAT` | 每秒一行状态，含 `fb=` `left=` `edeg=` `dIE=`（陀螺角−编码器角）`out=` `duty=` |
| `FWD` `REV` `BRK` `COAST` | 开环验证正转/反转/刹车/滑行（仅 IDLE） |
| `INFO` / `ENC` / `RESET` / `HELP` | 详细转储 / 编码器状态 / 恢复默认 / 帮助 |

`STAT` 一行样例：

```
STAT st=RUN fb=IMU tgt=0.000 yaw=0.062 cont=0.062 err=-0.062 left=129 out=-2 duty=1000 rate=-0.033 zt=0 enc=0 edeg=0.000 dIE=0.062
```

（`duty=1000` 是"短路刹车"的状态标记，不是满占空比。）

## 六、VOFA+ 使用

1. 数据引擎选 **FireWater**（默认，文本 `yaw:<Target>,<Yaw>\r\n`）或 **JustFloat**（小端 float + 帧尾 `00 80 7F`）；
2. 串口 115200 打开，通道数 **2**（ch0=Target，ch1=Yaw）；发 `RAW=ON` 变 3 通道（ch2=角速度）；
3. 建议 Y 轴范围 ±180°，X 轴显示最近 20s；
4. 曲线判据：Target 阶跃后 Yaw 应在 0.3s 内贴住，稳态两条线间距即静态误差。

## 七、调参步骤（陀螺反馈版）

> 上位机调参用 `tools/tune_yaw.py`；闭环阶跃与验收用 `tools/imu_verify.py`。
> **调参前先确认 `left=`**，开环试探务必正反交替，避免单向累积。

1. **上电预热 2~3 分钟**，确认 `IMU` 的 `gzraw` 稳定后再 `CAL`。
2. **确认方向**：给一个 0.2 s 的 `DUTY=160` 小脉冲，看 `edeg` 是增大还是减小。减小说明电机线反了 → `INV=ON`（或改 `MOTOR_DIR_INVERT`）。**方向反着进闭环就是正反馈，会一路加速**。
3. **测死区**：`DZ=0`，用 `DUTY=60/90/120/150/180` 逐个试，记下起转的最小占空比。
4. **核对符号**：手转 90°，比较 `Δedeg` 与陀螺积分 `Δgyro`（`gyro = edeg + dIE`）。符号必须一致（否则改 `GSIG`），比例应在 1±0.05（否则核 `CPD`）。**做这个比对前先 `ZUPT=OFF`**，否则慢转会只积到 72%。
5. **先编码器环**：`FB=ENC`（自动 30/1.5/2），`SET=30`/`START`，按 P→I→D 顺序整定。
6. **再陀螺环**：`FB=IMU`（自动 12/0.8/0），重复第 5 步。**不要照搬编码器增益**（见 4.1）。
7. **验收**：`SET=30` 看 `err`；拨开 30~45° 松手看回位；`LIMIT=300` 后 `SET=150` → `SET=-150` 看最短路径。

### 整定过程踩到的坑（都已在代码里修掉）

| 现象 | 根因 | 修法 |
|---|---|---|
| 目标一改转盘纹丝不动、随机复现 | 堵转检测的参考时刻只在 RUN 里更新，`START` 时沿用旧时刻 → 第一拍就 `FAULT:STALL` | `ctl_start()` 里重新打点；超时 600ms → 2s |
| `Ki` 越大越飘 | `OMAX` 只砍外层输出，PID 仍按 ±1000 判饱和，积分涨到 ±400 | `ctl_set_out_max()` 同步 `pid->out_max/min` |
| 闭环一上就满功率 | 死区 250‰ 是在 MPU 线拖住转盘时测的，实际只有 145‰ | 重测死区；换机构必须重测 |
| 反向脉冲被拒、单向累积撞限位 | `ctl_manual()` 守卫没考虑 `INV` 取反 | 用 `ctl_enc_dir()` 按真实转向判断 |
| 增量式的增益照搬位置式会乱抖 | `Kd·Δ²e/dt` 在 dt=5ms 上放大 200 倍 | 增量式用 `Kd=0`、自己的 Kp/Ki 量级 |
| **陀螺环 5Hz 自持振荡** | 粘滑冲击 ±400dps 直接喂给 `Kd` 与制动增强，每拍打满限幅 | 测速再低通 80ms；制动门限陀螺用 60dps；增益降到 12/0.8/0 |
| **yaw 以 −12dps 稳定跑飞** | 零偏在线学习把真实转动学成零偏（`BIAS` 到 12.7dps） | 双闸：编码器静止 500ms + 每次最多 ±4dps |
| **`START` 成功但下一拍变回 IDLE** | 用"每次开关串口"的方式拼命令，`START` 中途丢了（板子并不复位，`uptime` 继续涨） | 多步操作用单会话脚本（`imu_verify.py` 的 step/recover 都是一次会话内完成） |

## 十一、已知限制

- **静摩擦让"静态顶住"力有上限**：`out = Kp×误差`，误差超过约 25° 后就被 `OMAX=300`（40% 占空比）钳住不再增长，所以**用手慢慢推时感觉不到力随角度变大**；一松手速度上来，制动增强接管，回位力才充分（实测 45° 回位 0.26 s）。
  - v1.2.8 试过补一条"大误差 + 几乎不动 + 持续 500ms → 满档"的判据，但实测手推速度是 20~60dps，达不到 `<25dps` 的门限，实际不触发；该功能**保留但实际不生效**，按用户要求不再继续迭代。
- **回程间隙约 5°**：编码器反馈换向后有系统性偏差（见 4.11）。要根治只能改机械（预紧弹簧/消隙齿轮/提高传动刚度）。
- **陀螺零偏随温度漂**（几分钟内 ~0.1 dps/℃），必须"预热 2~3 分钟再 `CAL`"；`BIASAUTO` 只能在怠速时慢跟。
- **ZUPT 与慢速转动冲突**（只积 72%），`FB=IMU/FUSE` 默认关闭；若在 IMU 模式下强行打开，慢速手转与慢速爬行会失真。
- **粘滑特性决定分辨率下限**：小误差时占空比够不到静摩擦门槛，只能靠积分慢慢攒；短时（<1s）定位精度受此限制。
- `STALL` 堵转检测与"手推扰动"天然冲突（电机给力而编码器不动，两者在固件眼里一样），做手推测试前请 `STALL=OFF`。
- `FWD`/`REV` 默认 400 pm（约 487‰），转盘可到 300 dps 以上，**测试脉冲不要超过 0.1 s**。
- 增量式 PID 的限幅会丢掉部分增量信息，且 `Kd/dt` 在 5ms 上放大 200 倍，所以增量式必须用 `Kd=0`；默认仍是位置式。
- 陀螺 Yaw 是**上电后的相对角**（纯积分），没有绝对基准；要做绝对角度得换成带磁力计的 IMU 或加基准开关。
- 速度内环（串级）没有启用：`app_enc.c` 已提供 `enc_speed_cps()`，需要时可把位置环输出当速度指令再加一层 PI。
