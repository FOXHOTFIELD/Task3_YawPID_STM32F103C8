# 26 级第三期考核任务：TB6612 电机驱动与水平转盘偏航角闭环控制

基于 **STM32F103C8T6 + CubeMX/HAL** 的水平转盘闭环工程：TB6612FNG 硬件 PWM 驱动（正转 / 反转 / 刹车 / 死区补偿）、TIM4 定时器节拍建立 200Hz 控制周期、MPU6050 陀螺 Z 轴积分得到 Yaw、位置式/增量式 PID 带输出限幅与积分抗饱和、串口命令 `SET/START/STOP` + PID 在线整定、VOFA+ 双通道波形、软件限位、±180° 最短路径。另外接了电机自带的**正交编码器**，除了堵转保护与转速观测，还可以作为**独立的闭环反馈源**（`FB=ENC`）—— 真机整定就是先在编码器环上做完，再切回陀螺的。

- 版本：**v1.1.1**（真机整定完成，参数已写进默认值）
- 主控：STM32F103C8T6，HSE 8MHz × PLL9 = **72MHz**
- 工具链：Keil MDK 5.43a（ARMCC V5.06 + MicroLIB，-O2）
- 构建状态：**0 Error / 0 Warning**；Code 28948 B / RO 752 B / RW 240 B / ZI 1840 B；产物 `MDK-ARM/Objects/Task3_YawPID.hex`（84267 B）
- 主机端单元测试：**55 项断言全部通过**（`_tools/host_test/build_and_run_task3.ps1`）

### TB6612 电源（比引脚更容易接错）

```
 VM  <- 电机电源 6~12V（独立电池/电源，绝不可从开发板 5V 取）
 VCC -> 3V3   ★必须 3.3V：VIH = 0.7×VCC，VCC=5V 时门限 3.5V，3.3V 逻辑推不动
 GND -> 与开发板、电机电源负极共地
 VM-GND 就近并 100µF 电解 + 100nF 瓷片，抑制换向火花干扰 I2C
 AO1/AO2 -> 电机两根线
```

- **电机两根线本机是接反的**：`MOTOR_DIR_INVERT` 必须为 **1**，否则"正输出"会让编码器角减小，闭环直接变成正反馈往一个方向加速。默认值已经置 1，接线换了记得改回去。
- **不要开 TIM3 部分重映射**：它会抢走 PB4/PB5/PB0/PB1，和本工程的 STBY(PB0)、编码器/JTAG 脚冲突。
- PA15/PB3 原本是 JTAG 脚，工程里 `__HAL_AFIO_REMAP_SWJ_NOJTAG()` 只保留 SWD，因此可以安全用作编码器输入；两脚都是 **5V 容忍**，编码器用 5V 供电直连也不会打坏 MCU。
- MPU6050 平贴在转盘上，**陀螺 Z 轴与电机轴平行**，Yaw 就是 gz 的积分；AD0 接地为 0x68（代码会自动尝试 0x69）。
- 编码器装在**电机轴（减速箱之前）**，所以它测的是电机转角；折算到转盘的刻度是 `CPD`（每转盘度多少计数），默认 13.6，可 `CPD=` 现场标定。

## 四、控制原理要点

### 4.1 反馈源（`FB=`）：为什么先调编码器再上陀螺

闭环用的角度有三个来源，可以在线切换（运行中不允许切）：

| 源 | 角度 | 特性 |
|---|---|---|
| `FB=ENC` | 编码器累计角，`edeg += Δcount×SIG/CPD` | 不漂、分辨率 0.07°，但含减速箱齿隙 |
| `FB=IMU` | 陀螺 Z 轴积分 | 平滑、无机械耦合，但零偏会漂 |
| `FB=FUSE` | 互补滤波：陀螺负责高频，编码器用 2s 时间常数把低频拉回来 | 兼顾平滑与不漂 |

调参顺序就是先用 `ENC` 把机械和增益调对（不漂、没有振动噪声，问题好定位），再切 `IMU`/`FUSE`。本机默认 `FB=ENC`。

### 4.2 Yaw 积分用 DWT 计时，不用 `HAL_GetTick()`

1ms tick 在 5ms 周期上是 20% 的量化误差，直接把角速度积分成角度会带来系统性刻度误差。`DWT->CYCCNT` 是 72MHz 计数，dt 精度足够；无符号相减自动处理 59.6s 的回绕。

### 4.3 两个角度量

- `cont` 连续累计角：用于**限位**与 PID 输入输出；
- `yaw = wrap180(cont)` 显示角：VOFA+ 画的就是它。

从 +170° 到 -170° 时 `cont` 会走到 190°，这正是"最短路径允许跨 ±180°"与"限位必须按连续角算"能同时成立的原因。

### 4.4 最短路径

`err = wrap180(target - yaw)`，PID 的等效目标取 `cont + err`，于是 ±180 处既不跳变，也天然走短边。实测 +150° → −150° 时 `cont` 走 `149 → 171 → 210`，即**只转了 61°**，而不是 −300°。

### 4.5 陀螺零偏标定与 ZUPT

开机 1.5s 非阻塞标定，标准差给"静止质量"打分。ZUPT：角速度很小且（闭环时）输出也很小时连续 500ms 判定静止，**冻结 Yaw 积分**。注意 ZUPT 的静止计数有上限（`ZUPT_STILL_CAP_MS`），否则静止越久越难解冻，会把积分冻死。

### 4.6 死区补偿与实测特性

TB6612 输出不是"给了占空比就转"。真机实测（转盘自由、`DZ=0` 直接给占空比）：

| 占空比 | 0.4 秒转过 | 折算 |
|---|---|---|
| 60‰ | 0.00° | 不动 |
| 90‰ | 0.44° | 几乎不动 |
| 120‰ | 0.15° | 不动 |
| **150‰** | **12.2°** | 起动门限 |
| 180‰ | 16.8° | ≈40 dps |
| 300‰ | 38.8° | ≈100 dps |

所以死区取 **145‰**，高于它的任何非零力度都能推动电机。**注意这个值强依赖机构状态**：MPU6050 装在转盘上时它的线会拖住转盘，那时 200‰ 都推不动，死区看起来像 250‰ —— 换机构一定要重测。

### 4.7 小输出刹车（`BRAKE_OUT_PM`）

闭环输出小到推不动电机时（|out| < 6‰），固件不是滑行而是切 TB6612 的短路刹车。转盘本身有摩擦能停住，但带着速度冲过目标时先刹车能明显压超调。

### 4.8 PID 两个工程细节

- **微分先行**：微分项对测量值求导（`-Kd·d(meas)/dt`），改目标角时不会出现微分冲击；
- **条件积分抗饱和**：输出顶到限幅且误差还在往饱和方向推时，暂停积分累加；再叠加积分项自身 ±400‰ 的硬限幅。

★ **限幅必须同步给 PID 自己**：`OMAX` 以前只砍外层输出，PID 内部仍以 ±1000 判断饱和，积分在被砍掉的时间段里继续涨到 ±400，误差一反向就冲出一大截。`ctl_set_out_max()` 现在同时写 `pid->out_max/out_min`，这才是"Ki 越大越飘"的真正根因。

### 4.9 微分用外部测速

位置差分在 5ms 周期上量化太粗：编码器 1 个计数就是 14.7 dps 的台阶，`Kd` 一放大微分项就被量化噪声打死。代码里 `pid_set_rate_source()` + `pid_set_rate()` 允许把编码器/陀螺的干净测速直接喂给微分项（默认已启用）。

### 4.10 软件限位

默认 **±165°**（连续角）。接近限位 10° 内只允许往回收方向出力；越限立即刹车并进入 FAULT，必须 `STOP` 解除。本机排线已拆除，做 ±180° 演示时可直接 `LIMIT=300`。

### 4.11 开环也受限位约束

`DUTY/FWD/REV` 同样受限位守卫：剩余角度不足且方向朝外直接回 `ERR:LIMIT`；越限刹车；**点动超过 1.5 s 自动断电**（`MANUAL_TIMEOUT_MS`）。守卫按"电机实际转向"判断（`INV` 取反后的方向），早期没考虑取反，导致反向脉冲被全部拒绝、只剩单向累积，实测把转盘一路推到 +121° 撞限位。

## 五、串口命令

115200 8N1，命令与 VOFA+ 数据流共用同一串口；数据帧是 `yaw:...` 小写标签，命令是大写关键字，互不干扰。非法输入统一回 `ERR:<原因>`（`UNKNOWN_CMD` / `SYNTAX` / `RANGE` / `STATE` / `LIMIT` / `LINE_TOO_LONG`）。

| 命令 | 说明 |
|---|---|
| `SET=<角度>` | 设定目标角，如 `SET=-45.5`（也接受 `SET -45.5`）；超限回 `ERR:LIMIT` |
| `START` / `STOP` | 进入 / 退出闭环（STOP 后电机滑行断电） |
| `CAL` | 重新标定陀螺零偏（需静止，约 1.5s） |
| `ZERO` | 当前角度置 0，目标角同步平移（编码器角、融合角一并清零） |
| `KP=` `KI=` `KD=` | 单独整定一项，立即生效并回显 |
| `PID=<kp>,<ki>,<kd>` / `PID` | 三项一起设 / 打印当前值 |
| `MODE=POS\|INC` | 位置式（默认）/ 增量式 |
| `FB=IMU\|ENC\|FUSE` | 反馈源（仅非 RUN 状态可切；切到 ENC 会自动打开堵转检测） |
| `CPD=<n>` | 编码器每转盘度多少计数 |
| `SIG=1\|-1` | 编码器计数方向（接线反了免拆线，切换后角度归零需重新 `ZERO`） |
| `LIMIT=<度>` | 软件限位（30~300） |
| `DZ=<‰>` | 电机死区补偿量 |
| `OMAX=<‰>` | 闭环输出上限（同时写进 PID 的限幅，抗饱和才有效） |
| `KICK=<‰>,<ms>` | 换向"踢一脚"（默认关闭） |
| `INV=ON\|OFF` | 电机方向取反 |
| `ZUPT=ON\|OFF` | 静止冻结积分 |
| `BIASAUTO=ON\|OFF` | 怠速零偏在线跟踪 |
| `STALL=ON\|OFF` | 堵转检测（超时 2s） |
| `DUTY=<‰>` | 开环点动（仅 IDLE）；1.5 s 自动断电 |
| `STREAM=ON\|OFF` / `RAW=ON\|OFF` | 数据流开关 / 追加第三通道角速度 |
| `PROTO=FIRE\|JUST` | FireWater / JustFloat |
| `STAT=ON\|OFF` / `STAT` | 每秒一行状态，含 `fb=` `left=` `edeg=` `dIE=`（陀螺角−编码器角） |

`STAT` 一行样例：


## 六、VOFA+ 使用

1. 数据引擎选 **FireWater**（默认，文本 `yaw:<Target>,<Yaw>\r\n`）或 **JustFloat**（小端 float + 帧尾 `00 00 80 7F`）；
2. 串口 115200 打开，通道数 **2**（ch0=Target，ch1=Yaw）；发 `RAW=ON` 变 3 通道（ch2=角速度）；
3. 建议 Y 轴范围 ±180°，X 轴显示最近 20s；
4. 曲线判据：Target 阶跃后 Yaw 应在 0.6s 内贴住，稳态两条线间距即静态误差。

## 七、调参步骤（真机实测版）

> 上位机调参用 `_tools/tune_yaw.py`。**调参前先确认 `left=`**，开环试探务必正反交替，避免单向累积。

1. **确认方向**：给一个 0.2 s 的 `DUTY=160` 小脉冲，看 `edeg` 是增大还是减小。减小说明电机线反了 → `INV=ON`（或改 `MOTOR_DIR_INVERT`）。**方向反着进闭环就是正反馈，会一路加速**。
2. **测死区**：`DZ=0`，用 `DUTY=60/90/120/150/180` 逐个试，记下起转的最小占空比，`DZ` 取它（本机 145）。
3. **先 P**：`KI=0`、`KD=0`，`SET=30`、`START`，`KP` 从 5 起加。判据：静差随 `KP` 成正比缩小（静差 ≈ 起动门限/(KP×0.86)）。
4. **加 I**：`KI` 从 0 加到 3，静差消掉即可。**不要贪大**：`KI=8` 时 30° 阶跃超调反而涨到 2.7°（积分在限幅段积累）。
5. **加 D**：`KD=3~4`，压接近目标时的冲过头。
6. **小输出刹车**：`BRAKE_OUT_PM` 默认 6，太大不起作用、太大会在目标附近抖。
7. **验收**：`SET=30` 看 `err`；手推 30° 看回位；`LIMIT=300` 后 `SET=150` → `SET=-150` 看最短路径。

### 整定过程踩到的坑（都已在代码里修掉）

| 现象 | 根因 | 修法 |
|---|---|---|
| 目标一改转盘纹丝不动、随机复现 | 堵转检测的参考时刻只在 RUN 里更新，`START` 时沿用旧时刻，`now-旧值` 早已超时 → 第一拍就 `FAULT:STALL` | `ctl_start()` 里重新打点；超时 600ms → 2s |
| `Ki` 越大越飘 | `OMAX` 只砍外层输出，PID 仍按 ±1000 判饱和，积分涨到 ±400 | `ctl_set_out_max()` 同步 `pid->out_max/min` |
| 闭环一上就满功率 | 死区 250‰ 是在 MPU 线拖住转盘时测的，实际只有 145‰ | 重测死区；换机构必须重测 |
| 反向脉冲被拒、单向累积撞限位 | `ctl_manual()` 守卫没考虑 `INV` 取反 | 用取反后的实际方向判断 |
| 增量式的增益照搬位置式会乱抖 | `Kd·Δ²e/dt` 在 dt=5ms 上放大 200 倍 | 增量式用 `Kd=0`、自己的 Kp/Ki 量级 |

| 步骤 | 操作 | 期望 | 实测 |
|---|---|---|---|

## 十一、已知限制

- **IMU 目前不在机上**。固件为此做了两条兼容：`FB=ENC` 时找不到 MPU6050 直接进 `IDLE`（可以立刻 START），运行中 I2C 读失败也不报 `FAULT`，只当成"陀螺=0"继续跑。装上 MPU6050 后发 `FB=IMU` 或 `FB=FUSE` 即可切回陀螺主反馈；`INFO` 里 `imu:` 一行能看到当前状态。
- `CPD` 是估值。它只影响"编码器角度换算成多少度"，会同时缩放限位和增益单位；误差 15% 时 165° 的限位实际可能到 190°，所以调参期把 `LIMIT` 收到 120 更安全。精确标定方法：装上陀螺后手转 ±45°，比较 Δ`enc` 与陀螺积分 Δ`cont`，`CPD = Δcount / Δ角度`，再 `CPD=<值>`。
- `STALL` 堵转检测默认在 `FB=ENC` 时打开。**用手按住转盘制造扰动时它会误判**（电机给力但编码器不动），超时已放宽到 2s；做手推测试前最好 `STALL=OFF`。
- 增量式 PID 的输出限幅会丢掉部分增量信息，且 `Kd/dt` 在 5ms 上放大 200 倍，所以增量式必须用 `Kd=0` 和自己的 Kp/Ki 量级；默认仍是位置式。
- 陀螺 Yaw 是**上电后的相对角**（纯积分），没有绝对基准，长时间运行会缓慢漂移；ZUPT + 怠速零偏跟踪能压住静止漂移，大幅温漂仍需重新 `CAL`。
- 速度内环（串级）没有启用：`app_enc.c` 已提供 `enc_speed_cps()`，需要时可把位置环输出当速度指令。
